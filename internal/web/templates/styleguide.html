Tone

Six tones, mirroring domain.Tone one-for-one. Go decides which tone a thing is; CSS decides only what that tone looks like. Each carries three values that travel together: the line, the fill, and the ink that goes on that fill. A seventh colour here without a seventh domain.Tone means a template is choosing colour by eye again.

ToneMeansLineFill + ink
neutralNot started, or not applicable badge / callout fill
progressMendel is working; nothing needed from you badge / callout fill
waitingBlocked on you — the most important state in the app badge / callout fill
successFinished, and it worked badge / callout fill
warningSomething is off, nothing has failed badge / callout fill
failureFinished, and it did not work badge / callout fill

Mendel green is chrome, not a tone. A green button means “the main thing to press”, never “success”.

Type & space

Metric — $1,284.40

Page title — text-lg

Card title — text-md

Body text — text-base. The default for anything a person reads in sentences. Prose blocks are capped at a readable measure.

Secondary text — text-sm, ink-2. Descriptions and notes.

Meta text — text-xs, ink-3. Timestamps and table meta. This is the faintest text allowed to carry meaning; anything lighter is decoration.
