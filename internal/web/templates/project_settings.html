Repository

The HTTPS URL of the git repository Mendel writes to.
The branch Variations are based on, and that winners are merged into.
Needs write access to contents and pull requests, so Mendel can branch, push, and open PRs.
How to create one
  1. On GitHub, open Settings → Developer settings.
  2. Choose Personal access tokens → Fine-grained tokens, then Generate new token.
  3. Under Repository access, select only the repository above.
  4. Under Permissions, set Contents and Pull requests to Read and write.
  5. Generate it, and paste it here.
