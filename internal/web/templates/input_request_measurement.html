Why Mendel asks

Nothing is blocked on this. Without it, though, Mendel can show what a project has spent and not whether the spending is working — the roadmap says what is being built, and only these numbers say whether it is landing.

Asked weekly. A key result that can only be measured at the end of the quarter cannot tell anyone whether the work is going well while there is still time to change it, so it is worth rewriting rather than answering late.
